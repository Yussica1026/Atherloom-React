## 1. 原始产品与技术架构

- 产品定位：本地优先、仅供私人陪伴与共同生活使用的 AI 客户端。
- 原始视觉目标：桌面与手机端的视觉和交互尽量还原 Claude 官方 App 的安静、极简层级。
- 产品身份：保留 Atherloom 名称、原创图标与自身数据边界，不冒充 Anthropic 或 Claude 官方客户端。
- 原始后端：FastAPI 提供静态页面、REST 接口与流式聊天接口。
- 原始存储：电脑端以 SQLite 保存线路、人格、会话、消息、记忆、工具审计和各空间数据。
- 原始前端：单页应用通过 `/api/bootstrap` 初始化，通过 `/api/chat` 接收流式事件，其他能力走 `/api/*`。
- 多端结构：电脑网页/PWA 使用 FastAPI；Standalone 网页和 Android WebView 使用相同界面语义，但由浏览器本地存储和 Android 原生桥接管数据与模型请求。
- React 的职责：替换手写 HTML、全局状态与原生 DOM 事件绑定；不重写 FastAPI、SQLite、Relay 或模型协议。

## 2. 视觉与交互基线

### 默认 Claude 风格

| 角色 | 色值 |
| --- | --- |
| 页面纸张 | `#f7f6f2` |
| 侧栏暖灰 | `#eeede8` |
| 主表面 | `#fffefa` |
| 次表面 | `#f2f0e9` |
| 用户气泡 | `#e8e5dd` |
| 主文字 | `#2b2a27` |
| 次文字 | `#77736b` |
| 边框 | `#dedbd2` |
| Atherloom 陶橙 | `#c96442` |
| 陶橙深色 | `#a94f32` |

- 正文采用清晰的无衬线中文字体栈；欢迎标题和空间标题可使用克制的衬线字体。
- 左侧为固定会话与功能侧栏，中间为单一聊天阅读列，底部为圆角输入区。
- Assistant 正文以阅读流为主；用户消息使用靠右的暖灰气泡。
- 顶栏保持极简，只放当前会话和真正高频的状态/通话动作。
- 欢迎页只保留 Atherloom 陶橙线性标记和问候，不恢复已经删除的设备说明、占位引导、免责文案或上下文估算。
- Atherloom 图标继续使用交织字母 A、入口轨迹、纸张米白、墨黑棕和陶橙星点。
- 不使用会因系统差异变成彩色 Emoji 的核心图标；电话、欢迎标记等使用 SVG。
- 动效只用于启动标记、流式正文与明确状态变化；尊重 `prefers-reduced-motion`。

### 可选主题

- 跟随系统：自动使用暖米白浅色或暖黑灰深色。
- 默认/浅色：Claude 风格暖米白。
- 深色：暖黑灰，不改成纯黑霓虹界面。
- 水色、薄荷绿、丁香、腮红：只是用户可选主题，不能替代默认设计方向。
- 外观设置保留字体大小、消息密度、流式显示速度和代码主题。

### 响应式与触摸规则

- 覆盖桌面、普通手机、超窄屏、横屏、刘海/灵动岛、Android 状态栏、底部手势区和动态浏览器地址栏。
- 使用 `100dvh`、安全区变量和 `visualViewport`/原生 resize 处理软键盘。
- 手机侧栏必须有关闭按钮、遮罩关闭、选中后关闭和 Android 返回键关闭路径。
- 华为曲面屏长按删除继续采用独立触摸路径；长按后显示全宽删除行，不使用长按即删。
- 主聊天 Enter 只换行，发送必须点击发送键。
- 自主提问选项保留真实 touch 兜底、滑动阈值、选中高亮、填入输入框和明确发送提示。
- 设置、弹层和全屏空间必须有明确的层级与焦点管理，不能依赖超高 `z-index` 互相竞争。

## 3. 必须迁移的当前功能

### 3.1 聊天与会话

- 新建、选择、重命名、置顶、星标、归档、搜索和软删除会话。
- 会话标题搜索与消息全文搜索。
- 每个会话独立草稿；切换会话不丢草稿。
- 后台生成绑定原会话，不污染当前窗口。
- 流式与非流式生成；首字及时出现、稳定小批量绘制、靠近底部时自动跟随。
- 停止生成：取消请求和待绘制队列，保留已生成正文。
- Markdown、代码块、思考/推理折叠、记忆来源、工具过程和 Token usage。
- 复制、修改、重新 Roll、版本左右切换、删除当前版本、删除全部版本和从消息创建分支。
- 失败回答仍保留可用的复制、修改和重新 Roll。
- 分享时导出脱敏 Markdown。
- 多附件：拍照、相册、图片、PDF、文本、Markdown 和代码文件；本地预览、移除、格式与大小限制。
- 图片可使用独立视觉线路；不支持视觉的线路要明确说明。
- 快捷短语、指令注入、世界书选择和本轮请求检查。
- 当前人格状态条、输入状态、启动会话策略和分时问候。

### 3.2 API 线路与模型

- 多线路随时切换，历史消息保留当时的线路和模型来源。
- OpenAI 兼容、Anthropic Messages、DeepSeek、GLM 及自定义反代地址。
- 每条线路保存显示名、协议、Base URL、API Key、模型列表、自定义请求头和启用状态。
- 拉取模型、真实鉴权测试、手动填写模型和移动端可靠下拉选择。
- 线路编辑必须有高亮、定位和明确的“正在编辑”反馈。
- 温度、Top P、最大输出、thinking、流式开关、流式速度和图片理解线路。
- Anthropic 显式缓存、OpenRouter/兼容网关缓存模式与稳定/动态上下文分层。
- API Key 不回显原文；Android 继续通过原生安全桥和系统安全存储处理秘密。

### 3.3 人格工作区与隔离

- 人格创建、编辑、删除、头像/名称、系统指令和专属模型线路绑定。
- 每个人格独立的对话、记忆、向量索引、动机/欲望、游戏存档、日记、留言、梦和往来数据。
- 人格切换统一保存草稿、加载人格数据，再按“继续最近对话/自动新建”策略进入聊天。
- 线路与人格不匹配时由后端拒绝，不能静默串线。
- 人格提示词支持身份关系、说话方式、边界、消息模板、可用变量和注入位置。
- 实际线路、模型和本轮注入内容应允许用户查看与控制。

### 3.4 摘要、上下文与世界书

- 本地快速命名、当前模型命名和关闭自动命名。
- 自动滚动摘要：触发轮数、自定义提示词、模板变量、当前摘要和可追溯历史版本。
- 主动压缩：生成状态、独立超时、失败保留原文和换线重试。
- 压缩后保留最近 5 轮原文是已确认待补项，React 版必须纳入验收。
- 世界书创建、编辑、删除、条目 CRUD、关键字匹配和导入/导出。
- 每个会话独立选择多个世界书；可在输入区取消。
- 世界书支持系统提示前/后、对话历史前/后等注入位置。
- 稳定人格/规则/世界书与动态时间、媒体播放点、游戏结果、剧场检索分层。

### 3.5 记忆系统

- 当前人格、共享范围和未分配旧记忆三种所有权视图。
- 类型：事实、偏好、关系、承诺、事件、情感、摘要、日记及其他。
- 字段：标题、内容、重要度、可信度、来源类型、生效/失效时间和来源消息。
- 状态：当前、待确认、遗忘、替代、归档和回收站。
- 新增、编辑、星标、软删除、恢复、候选确认和拒绝。
- 记忆详情、修改历史、审计、恢复旧版本和关联图。
- 事实替代、关联、合并、生命周期衰减、回忆次数和最后召回时间。
- BM25/关键词召回、向量召回、融合重排、来源显示、阈值、条数和索引重建。
- 本地 embedding 和云端 embedding；按内容哈希缓存，不混用不同模型/维度索引。
- AI 重要度评估预览与勾选应用。
- AI 管理记忆开关、记忆工具操作规程和工具权限。

### 3.6 工具、联网与 MCP

- 权限三档：始终允许、每次询问、禁止；删除等高影响操作不得被批量设为始终允许。
- 工具分组：网络、文件、记忆、生活记录、内容和高风险操作。
- 内置公开网页搜索、百科、Tavily、Brave 和自定义搜索 API。
- 内置记忆搜索/创建/更新、日记、留言、生活记录、游戏、往来与会客厅工具。
- 多轮 Agent 工具链：允许先搜索、再调用其他工具，直到证据足够。
- OpenAI 工具调用、Anthropic 工具调用、DSML 兼容和 reasoning 保留。
- MCP 管理中心：Streamable HTTP 与桌面 stdio、连接测试、工具发现、逐工具权限和最近调用审计。
- Android 不能启动本机 stdio；只支持远程 MCP 与本地内置工具。
- 工具审计显示会话标题、触发工具的用户原话、结果与时间。

### 3.7 日记、留言、梦与生活簿

- 私人日记、共同日记和 AI 日记；作者身份明确。
- 留言板：写给当前人格、是否允许人格读取、直接回复和回复关联。
- 一次性/每日定时留言；网页重开补投、跨标签锁、租约、去重和失败重试。
- 用户回复可安排十分钟人格唤醒；不伪装成移动系统后台通知。
- 梦库：生成梦、隔离、认领和按人格保存。
- 生活记录：记账、生理期、吃饭等，按用户授权决定是否进入人格上下文。
- 生活簿：纪念日、备忘、倒计时和生活手账视图。

### 3.8 动机/欲望与自主生活

- 九维驱动、事件冲击、惊喜、耦合、自然心跳、念头、执念和 SQLite/本地持久化。
- 状态按人格隔离；聊天每轮可推进，后台按真实时间补算。
- 当前状态卡显示一位小数、累计心跳、下次心跳和运行方式。
- 支持少量补算、真实时间补算、冻结、手动心跳和重置。
- AI 自主生活计划：周期、安静时段、费用/频率边界、手动唤醒和审计。
- 动机不得绕过工具权限或执行高影响外部操作。

### 3.9 珍藏与共创空间

- 珍藏：收藏消息、搜索、移除和与消息版本联动。
- 一起读书：本地书架、格式识别、UTF-8/GB18030/GBK/Big5/UTF-16 解码、PDF 文字提取、书签、批注、进度、独立陪读消息流和“问当前内容”。
- PDF：网页使用本地 PDF.js；Android 使用原生 PDFBox/文件流，不能把整本 PDF Base64 塞进 WebView。
- 一起看电影：本地视频/直链、SRT/VTT、播放进度、字幕纸带、独立陪看消息流、“问这一幕”和真实画面/编解码诊断。
- 一起听歌：多文件歌单、播放/暂停、上一首/下一首、进度、本机续播、LRC、系统媒体键和独立陪听消息流。
- 听歌视觉保留私人磁带卡座；减少动态效果时卷轴停止。
- 角色剧场：故事设置、玩家名、角色阵容与独立线路、专用旁白、预设、世界书、作者开场/AI 开场、逐回小说正文、连续剧情档案、TXT 导出、收藏、重 Roll、删除并撤回后续回合。
- 角色剧场幕后讨论使用当前人格与旁白线路，独立保存，不写入正式正文；保留核心设定、清空、重 Roll 和竞态取消。

### 3.10 游戏与共同生活

- 游戏目录和每个人格独立存档。
- 云芽庭院：种花、宠物、房间/地图、真实时间结算和授权人格照料。
- 乌有乡：原版真实地球旅行工具与观察页。
- 云汀钓记：钓鱼、鱼饵、云贝、水域、出售和日志。
- 抓娃娃机：左右移动、下爪、每日签到、收藏柜和出售。
- 云纹老虎机：只使用游戏内云贝的确定性三轴玩法。
- 星潮合成：2048 规则、用户/人格双模式、触摸/键盘/按钮、悔棋、重开和人格想法。
- 雾径迷宫：随机可达地图、持续关卡、有限视野和轮流探路。
- 余烬地牢：探索、攻击、格挡、休整、楼层/生命和持续冒险。
- 当前人格可以从聊天调用真实宿主游戏工具，结果作为已验证上下文回到聊天。
- AI 支持自主决定或固定 3/6/9 回合；逐回合更新、预算、超时、停止和白名单动作。
- 游戏房间拥有独立聊天和待发送队列；游戏重绘与聊天生成不能互相覆盖。
- 人格没有真实想法时不伪造心声；残缺 JSON 不当作心里话。

### 3.11 往来、信箱与 AI 会客厅

- “往来”是人格自己的信箱、联系人、会客厅和通信记录总入口。
- 联系人申请需要 AI 意愿和用户批准双重同意；支持封禁。
- 人格可查看信箱、逐封写信/回信；工具结果必须来自真实数据。
- 会客厅支持一次性邀请码、最多四席、人格自主声明名字/物种/性别。
- 提题、独立投票、主持权转交、完整内容可见性投票、串行发言、插话请求和主持确认。
- 投票和发言窗口 120 秒；客户端模型请求 105 秒收口，给提交预留网络时间。
- Relay 状态与本地模型状态分层显示；上游 502、空正文、迟到稿和 Relay 停止不能混为一类。
- 正式剩余、真实流程已用和准备补时三条时间轨道。
- App 重启/前台恢复可找回活动房间；孤儿房有空闲关闭规则。
- 安全命中触发移出和拉黑；正常记忆检索不能被误判。
- 归档默认折叠，只显示题目与短摘要；展开显示允许保存的详情和检索关键词。
- 关键词只来自题目与可见总结，不读取隐藏原文。
- 用户只能申请删除会谈归档，由归档所属人格独立决定；同意后软删除。
- MCP 兼容层与 Relay 是独立项目，React 前端只接它们的公开协议。

### 3.12 数据、备份、健康与发布

- 本地快照、完整导出、Android 原生文件保存、恢复前快照和选择性恢复。
- API Key、MCP Token 等秘密不能明文进入备份。
- 数据健康、版本/更新、记忆统计和最近同步状态。
- PWA Manifest、离线壳、缓存升级、专用修复页和 Service Worker 重置。
- Android WebViewAssetLoader、文件选择、返回键层级、原生网络桥、流式回调和系统安全存储。
- 网页、PWA、Android 共享界面语义，但必须保留各自能力边界。

## 4. 明确不迁入本仓库的项目

- 石头狗及 AstrBot Touch Pet：独立项目。
- AstrBot Memory System 与 Desire System：独立插件项目。
- Atherloom Escape/心织密室：独立游戏与 Relay；React 客户端以后只做受控入口。
- 《栖光物语》/云芽庭院独立 RPG：独立仓库；不要和 Atherloom 内置的轻量云芽庭院混为一体。
- OnlyRouter/OpenRouter/Cloudflare Worker：基础设施项目，不是 React UI 源码。
- Relay MCP 服务：独立仓库；这里只放连接器和 UI。
- 公开 Codex/阿栈线路已撤下；未经重新确认，不进入网页或 APK。

- QQ 直连 Codex 后台桥只留待办。
- Atherloom 前端 Codex 本地安全桥已撤下并暂缓。
- 棋牌室/斗地主仍是未完成候选，旧入口曾下架；不能作为已完成模块迁移。
- 实时语音通话、睡眠陪伴和系统级后台通知仍有平台限制。
- 压缩后保留最近 5 轮、工具失败问题卡和普通聊天首 token 卡顿是已确认待修项。

## 6. React 目标结构

```text

  domain/              # Provider、Persona、Conversation、Memory 等类型
  adapters/
    fastapi/           # 电脑端 REST + 流式聊天
    standalone/        # PWA/Android 本地数据与原生桥
    relay/             # 往来与会客厅
  features/
    chat/
    providers/
    personas/
    context/
    memories/
    tools/
    writing/
    correspondence/
    shared-spaces/
    games/
    backup/
```
