## 人格数据隔离边界

本轮已经保证聊天侧的会话、当前窗口、草稿、启动策略和专属线路不串人格。旧版要求的完整人格工作区还包括记忆/向量、欲望、游戏、日记、留言、梦、生活记录、往来与会客厅；这些数据的旧 FastAPI 表仍按人格保存，但 React 尚未提供对应功能页，因此不能写成“完整人格隔离已迁移”。

## 仍使用旧版的完整模块

- 自动总结、主动压缩、完整记忆生命周期与向量索引。
- MCP 管理、工具权限、联网搜索与多轮工具调用。
- 日记、留言、梦、生活簿、动机/欲望与自主生活。
- 珍藏、一起读书、一起看电影、一起听歌、角色剧场。
- 全部游戏、游戏房间聊天与人格自主游玩。
- 往来、信箱、联系人、AI 会客厅与 Relay 恢复。
- 数据健康、更新/修复页、加密备份、云端增量同步。
