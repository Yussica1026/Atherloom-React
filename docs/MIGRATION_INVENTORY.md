## 数据与运行模式

- FastAPI 模式继续使用旧版 SQLite、完整记忆/MCP/工具后端。
- Android 地址留空时使用 Standalone 本机数据；API Key 只进入 Android 加密存储，模型请求由原生网络桥发送，流式线路由原生桥直接读取上游 SSE。
- 浏览器/PWA 使用同源 FastAPI 或用户填写的服务器根地址；共同空间媒体正文留在设备端。
- 往来审批、封禁、安全检查与实际投递只在支持对应接口的 FastAPI 模式执行；Android 纯本机模式明确禁用，不用本地模拟记录伪造送达。
- 标记共享的本机生活簿、日记、留言和已认领梦境目前只在 Android Standalone 注入人格上下文；FastAPI 模式保留本机记录但明确提示聊天端暂不读取。
- 两种模式共享 React 组件和领域类型；平台能力差异在适配器与界面说明中显式呈现。
